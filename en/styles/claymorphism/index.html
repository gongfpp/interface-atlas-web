Claymorphism

黏土风

Aliases:黏土风黏土拟物软糖质感设计膨胀立体卡片3D黏土按钮橡皮泥风格Clay 3DPuffy UI

OverviewStyle labVariantsImplementationPrompts

What is it

A visual language that molds controls from soft clay: generous radii on pastel grounds, with a double shadow — an inner concave plus an outer inflated drop — so elements feel like air-puffed clay: round, plump, squishable. A tactile middle ground between neumorphism and 3D cartoon.

Design spec

Typography

Rounded sans

Color

Lavender base #EDF0FF, white cards, violet #6C7BFF

Border

Borderless with 22px+ radius

Shadow

Outer + inset shadows create the clay feel

Spacing

Puffy spacing, elements float apart

Motion

180–240ms soft elastic press transitions; honour prefers-reduced-motion

States

Hover lifts and deepens the outer shadow; focus shows a visible violet ring; active becomes an inset press; disabled flattens and desaturates; error uses a coral inset

What to look for

  • 01Use Claymates’s original navigation and primary CTAs; inspect content and return paths, not just click notices.
  • 02Complete the Claymates task, then change inputs or undo and inspect the matching result/state.
  • 03Check reflow, focus and validation with keyboard and 390px / 320px viewports; distinguish toolbar reload from in-page clearing and inspect reset-on-reload boundaries.

✓ When to use

  • Kids, education and casual games that want approachable tactility
  • Relaxed social and consumer brands signaling cuteness and ease
  • Mobile touch interactions that want tactile feedback

✕ When not to use

  • Professional, fintech and enterprise contexts — clay reads unserious
  • Dense dashboards where inflated shadows eat space and focus
  • Heavy dark-mode usage where pastel inflation is hard to sustain

Implementation

border-radius: 20pxbox-shadow: inset 0 -6px 12pxbox-shadow: 0 12px 24pxpastel

Inflation formula = big radii (20–32px) plus three shadows: a large blurred same-hue drop (e.g. 0 14px 28px at 35% of the base color), an inner bottom press (inset 0 -8px 16px), and an inner top light (inset 0 3px 6px white). Tinted shadows must stay in-family — never grey. On press, shrink the drop and deepen the inner shadow to feel squeezed. Dark clay uses deep grey with a darker same-hue drop.

Floating Action Button

别名:悬浮按钮浮动按钮悬浮球右下角那个圆按钮FABfloating action button

概览交互实验室不同风格形式与用法实现要点复制 Prompt

这是什么

锚在视口角落、悬浮于内容之上的圆形按钮，承载当前页面唯一的主操作（新建、撰写、扫码）。 用阴影和位置宣告「我在所有内容之上」，比行内主按钮更醒目，但一屏只应有一个。点击后可展开 为带标签的扩展形态，或扇出一组快捷动作。

名词辨析

悬浮按钮不是「更显眼的主按钮」：主按钮嵌在页面布局里、随内容滚动；悬浮按钮脱离文档流、 常驻视口角落并覆盖在内容之上。判断标准是它是否悬浮在滚动内容之上，而不是颜色有多亮。

✓ 适用场景

  • 页面有唯一、高频、正向的主操作（新建、撰写）
  • 底部拇指热区需要常驻入口
  • 工具型界面需要比行内按钮更强的操作召唤

✕ 不适用场景

  • 有多个并列主操作（并列会互相削弱，用底部操作条）
  • 操作是破坏性的（删除、清空）
  • 会遮挡关键内容或底部导航

实现要点

position: fixedborder-radiusbox-shadowtransformtransition

position: fixed（或 absolute 于滚动容器外）锚定角落，圆形用 border-radius: 9999px； 抬升靠 box-shadow 多层阴影而非描边。扇出的子动作用 scale + opacity 依次错开出现， 主按钮旋转 45° 变关闭。按压 scale(0.94) 反馈；触控目标不小于 48px；尊重 prefers-reduced-motion。

按钮Button

用可点击的色块触发一个明确的动作，是界面中最基础的操作入口。 通过填充、描边、幽灵等视觉层级区分主次操作，按压时有即时的下沉反馈， 繁忙时进入加载态并禁用点击，防止重复提交。

组件替代方案

⌨ 按住按钮不放观察缩放；Tab + Space 同样可触发

按压反馈Press Feedback

用户按下按钮、卡片等可点击元素时，元素轻微缩小（通常 0.95～0.98）， 松开后弹回。一个几十毫秒的细节，让界面"手感"立刻从网页变成实体按键。

动效搭配使用

波纹从真实触点扩散，400ms 放大渐隐；点哪儿哪儿起波

点击涟漪Ripple

点击位置向外扩散一圈半透明圆形波纹后消散，把"点中了哪里"可视化。 Material Design 的标志性按压反馈， 让无生命的点击立刻获得物理感——像石头落进水面。
